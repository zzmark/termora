# 终端录制与回放

点击工具栏「终端日志」→「设置」，选择纯文本、样式文本或 Asciinema 格式。停止记录后可以更改设置。选择 Asciinema 后，SSH、本地终端和 WSL 等终端会话的输出和尺寸变化以 asciicast v3 格式保存。录制从开启日志后收到的事件开始。要录下全屏程序的完整画面，请先开启记录，再运行该程序。

勾选「开启 zstd 压缩」后，结束记录或关闭会话时会在后台压缩文件。压缩前的文件带有 `.pending-zstd` 后缀。压缩完成后生成 `.log.zst` 或 `.cast.zst` 并移除原文件。压缩中断或失败时原文件保留，Termora 下次启动时会在日志目录下重新处理。

「录制键盘输入」仅用于 Asciinema，默认关闭。开启后，发送给终端的按键和输入法提交会写为输入事件，其中可能包含没有回显的密码。

通过「终端日志」→「打开日志浏览器」打开 `.cast` 或 `.cast.zst`。支持 asciicast v2 和 v3，回放时可以暂停、继续、调整倍速、从头播放和显示录制的输入。底部进度条显示当前时间和总时长，拖动后会重建目标时间的终端画面。`.log` 和 `.log.zst` 继续在日志查看器里打开。

Termora 写入的 asciicast 文件头包含录制开始时间、会话显示名和初始终端尺寸。录制开始时间可能晚于 SSH 建连时间。连接地址、用户名、认证方式和其他连接配置没有对应的标准字段，也不会从 Termora 的连接配置写入文件。会话显示名和终端输出本身可能包含主机或用户信息。
