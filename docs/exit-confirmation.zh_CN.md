# 退出确认

关闭最后一个主窗口时，如果没有打开的连接标签页，直接关闭窗口，不再弹出“你要退出 Termora 吗？”确认框。

连接是否计入退出确认，以标签页是否仍然打开为准，不检查会话是否在线：

- SSH、本地终端、WSL、Telnet、RDP、VNC 和串口等主机会话标签页计入确认，已断开但未关闭的标签页也计入。
- 文件传输页中已选择远端主机的标签页计入确认，包括连接中、连接失败或已断开的标签页。
- 从主窗口移出的独立连接窗口也计入确认。
- 欢迎页、日志回放、文件传输的空选择页和本地目录页不计入连接。

仍有连接标签页时保留原退出确认。后台运行模式和多主窗口关闭流程沿用原有行为；本调整只改变原先会弹出退出确认框时的条件。

## 验证

在有可用桌面的环境运行：

```powershell
.\gradlew.bat :test --tests app.termora.ExitConfirmationTest
```

测试使用系统临时目录中的独立配置，验证连接标签页判断及真实 Swing 窗口关闭、确认、取消、独立窗口和文件传输页流程，并覆盖多主窗口和 Windows 后台运行分支。文件传输状态使用测试数据，不会连接外部主机。测试会临时创建自己的窗口；无桌面环境会跳过此测试类，不能视为行为验证通过。
