# SSH 终端系统状态栏

每个 SSH 终端底部显示独立的紧凑单行状态栏，依次为：主机信息、CPU 使用率、CPU 最近 32 次有效采样、内存使用、网络上传、网络下载、当前用户、存储使用率。窗口空间不足时横向滚动，滚轮可移动状态栏。

CPU、内存、网络上传和网络下载模块按当前字体预留固定宽度，数值位数或单位变化不会挤动后续模块。存储块按根挂载点 `/` 优先、其余按总容量从大到小排列；容量相同时按挂载路径排序。

内存容量和网络速率的数值最多展示四个数字：小于 100 时保留两位小数，例如 `99.99MB`；达到 100 时显示整数，例如 `100MB`、`1023MB`。数值四舍五入，舍入达到 1024 时进位到下一个单位；固定宽度按 `99.99` 和四位整数中较宽的格式预留。CPU 和存储使用率继续显示整数百分比。

“设置 → 常规 → 显示 SSH 系统状态栏”默认开启，修改后立即应用于所有 SSH 终端，无需重启。关闭后隐藏整个状态栏并暂停其后台采集，保留各模块的显示偏好；重新开启时恢复显示并重新建立采样基线。原“系统信息”浮窗独立可用：浮窗打开时继续共享采集，关闭浮窗且状态栏已关闭时停止采集。

## 指标含义

- 首版支持 Linux SSH 主机，需要允许 SSH Exec 命令，并提供 `/proc`、`uname`、`hostname`、`who` 和支持 `-PT -B1`、`-hP` 的 `df`。
- CPU 通过 `/proc/stat` 的差值计算，空闲时间包括 idle 和 iowait；历史从左到右由旧到新，不足 32 次时保留空位。采集目标间隔为 1 秒，不代表严格每秒完成。
- 内存显示已用量 / 总量，优先以 `MemTotal - MemAvailable` 计算。
- 网络上传为远端发送，下载为远端接收；使用 `/proc/net/dev` 的计数差值和远端 uptime 间隔计算，汇总非回环接口。接口新增或计数重置时先建立基线；桥接、隧道和虚拟接口可能重复统计，汇总值不等于物理出口流量。
- 当前用户是 SSH 会话账户，不跟随交互 Shell 中的 `sudo`、`su`。悬停展示最近一次 `who` 的完整输出；没有登录记录时内容可以为空。
- 每个存储块显示挂载路径和 `df` 使用率。状态栏排除 overlay、tmpfs、devtmpfs、shm、proc、sysfs、cgroup 等临时或伪文件系统，以及只读 squashfs 镜像；保留普通磁盘和网络文件系统。
- 存储悬停展示完整 `df -hP` 输出，包含被状态栏过滤的文件系统。详情采用等宽字体，保留表头和列对齐。

## 右键操作

右键模块可复制当前显示文本；有详情时可选择“复制详情”，内容与悬停提示一致。CPU 历史复制为按旧到新排列的百分比列表。网络详情包含各接口的上传、下载速率；存储复制当前挂载点文本，复制详情则取得完整 `df -hP` 输出。

分隔线下直接列出八个模块的勾选项，不使用子菜单。设置立即应用于所有 SSH 状态栏并持久化；存储选项统一控制所有挂载点。右键空白处只显示勾选项。全部隐藏后仍保留底栏，可通过右键恢复。

## 采集与连接

采集复用已认证的 SSH 连接，每轮打开一个短期 Exec 通道，批量读取指标后关闭，不向交互终端注入命令。CPU、内存和网络目标间隔为 1 秒，请求不会重叠；主机、用户、`who` 和磁盘详情每 10 秒采集一次。悬停和复制使用缓存，不触发命令。

原“系统信息”浮窗保留，与状态栏共享同一采集器。断连后停止采集，重连清空差值基线与历史。关闭标签页释放采集任务和通道。采集失败显示不可用状态；详情超过 20 秒未成功更新时不再作为当前数据展示。不支持的系统显示对应提示。
